# DataPolish SEO notes

Nothing here has been submitted anywhere yet; every step below needs the live domain (owner action).

## Search Console (after the domain is live)

1. Search Console → Add property → **Domain** → enter the bare domain.
2. Copy the `google-site-verification=…` TXT value and add it as a TXT record at the domain's DNS root (`@`). Wait for DNS, then press Verify.
3. Sitemaps → submit `https://<domain>/sitemap.xml` (generated by `src/app/sitemap.ts` from `APP_URL`).
4. Check Pages → "Why pages aren't indexed" a week later. `/account`, `/admin`, `/login` and the auth flow pages are disallowed in `robots.txt` and marked `noindex`; that is intended.
5. Optional: Bing Webmaster Tools → import from Search Console.

## What is in place

- `metadataBase` = `APP_URL`, canonical URL per public page, Open Graph title/description.
- JSON-LD with the CSP nonce: `SoftwareApplication` with offers built from `DATAPOLISH_CATALOG` (home, pricing), `FAQPage` (pricing), `Article` (each guide).
- `robots.txt` disallows `/api/`, `/account`, `/admin`, auth pages and invitation links.
- No testimonials, user counts, logos or ratings anywhere: there are none yet.
