# WebhookTrail SEO notes

Nothing here is done yet: every step needs the live domain (owner action, see `docs/OWNER-ACTIONS.md` at the repo root).

## Search Console

1. In Google Search Console add a **Domain** property for the WebhookTrail domain.
2. Publish the `google-site-verification=…` TXT record it shows at the DNS provider (root of the domain). Wait for DNS, click Verify.
3. Sitemaps → submit `https://<domain>/sitemap.xml` (generated by `src/app/sitemap.ts` from `APP_URL`).
4. Bing Webmaster Tools: import the property from Search Console.

`APP_URL` must be the canonical https origin: it feeds `metadataBase` (canonical URLs, Open Graph), the sitemap and robots.txt.
